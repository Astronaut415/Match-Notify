DBD Match Notifier
программа для уведомлений о найденной катке в Dead by Daylight.


Функционал:

Автоматическая привязка Telegram-бота

Уникальный код привязки для каждого компьютера

Поиск катки по шаблону изображения

Интерфейс минималистичный

Минимальная нагрузка на CPU

Вы можете сами выбирать какие скриншоты будет видеть программа в папке screenshots. Я конечно добавил скриншотвы свои, но из-за разных решейдов и тому подобных всяких настроек со цветами.

Установка

Сначало установите python. я использовал python-3.12.0-amd64 - прямая ссылка - https://www.python.org/ftp/python/3.12.0/python-3.12.0-amd64.exe

Открой терминал в папке программы и выполни:

pip install -r requirements.txt

Далее запускайте программу и наслаждайтесь уведомлениями

Если вы нашли какие-то ошибки, хотели бы увидеть доработки или что-то ещё, то пишите в тг @Astronaut415
